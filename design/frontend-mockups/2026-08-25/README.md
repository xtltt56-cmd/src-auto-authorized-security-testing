# SRC-Auto 前端升级视觉稿（2026-08-25）

这组图片是三期升级计划的前端视觉参考，不是对现有 PowerShell WinForms 界面的直接替换。实现时应继续保留现有的本地路径、授权门禁、人工确认和“真实目标不会自动执行”约束。

## 视觉实现要点

- 主色保持深海军蓝 + 明亮蓝色操作色；绿色只表示安全/健康/已完成，橙色表示待人工确认，红色只用于高风险或排除范围。
- 所有高风险操作都应有明确的前置条件、范围摘要、停止按钮和审计记录；默认状态是“仅本地回环靶场”或“仅离线审阅”。
- 目标录入、范围预览和会话页必须显示允许主机、端口、排除项、范围哈希以及是否会产生网络请求。
- AI 设置页不得显示或回填明文密钥；关闭远程 AI 时不得触发网络调用，连接测试和单次审阅都要经过人工动作。
- Findings 页不把候选项直接称为“漏洞”，应区分“候选发现 / 待人工复核 / 已确认”，并保留最小化证据和复现前置条件。

## 下一步落地顺序

1. 先把工作台、目标录入、范围预览和会话门禁映射到现有控制台的真实按钮与命令。
2. 再加入发现/报告中心的筛选、证据查看和补天草稿导出。
3. 最后将 AI/工具设置、靶场健康和蓝队被动分析接入现有本地状态命令；任何真实目标主动测试仍须人工确认。
