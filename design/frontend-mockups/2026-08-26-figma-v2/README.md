## 本次交付

设计文件包含一个统一的桌面端页面总览，画板尺寸统一为 1440 × 900，使用简体中文和 `Noto Sans SC` 字体。页面按照统一的深蓝侧栏、浅灰画布、蓝/绿/橙/红安全状态体系整理。

1. `00 设计规范与安全状态`：颜色、排版、安全状态、页面交付清单。
2. `01 工作台`：运行概览、快速开始、最近任务、系统就绪度。
3. `02 本地靶场`：Juice Shop、DVWA、WebGoat 回环服务、回归验证和历史记录。
4. `03 目标与授权`：目标状态、授权资产、测试窗口、速率上限、禁止项和新建表单。
5. `04 授权目标启动确认`：Scope/计划哈希、请求预算、并发与速率、人工确认清单。
6. `05 会话与任务`：授权审阅、被动请求、API 对比、独立裁决、报告草稿流水线。
7. `06 代理与 API 复核`：Burp 手动代理、OWASP ZAP API、测试账号会话和对象差异。
8. `07 发现与报告`：严重度、置信度、赏金就绪度、发现清单和报告草稿。
9. `08 蓝队被动分析`：授权域名、被动暴露面、证书/DNS/安全头和保护建议。
10. `09 AI 与工具`：本地模型、DeepSeek、OpenRouter、远程调用次数、密钥和连接测试。
11. `10 审计与设置`：安全策略、目标状态机、操作等级、日志、密钥和恢复目录。

## 固定安全交互

- 真实目标默认显示“禁止执行”或“待人工确认”，不会由启动器自动访问。
- 唯一的网络操作入口是 `04 授权目标启动确认`，必须人工核对授权证据、测试时间窗和请求预算。
- 所有页面保留全局“立即停止”入口；停止后保存会话和审计记录。
- 自动提交永久关闭；平台只生成可人工修改的报告草稿。
- 远程 AI 每次会话单独启用；选择“否”时本次会话不得调用远程模型。
- 本地靶场仅允许 `127.0.0.1` 回环地址，不能与真实目标页面混用。
- “蓝队被动分析”独立于本地靶场，输入域名前必须提供所有权或受托保护证明。

## 开发落地建议

当前 Figma 文件是视觉和交互规格，不会替换现有 PowerShell 启动器。后续实现建议使用 React/TypeScript + FastAPI，本地控制器和现有 PowerShell 启动器继续保留为兼容入口。实现时优先复用 Figma Simple Design System 的 Button、Input Field、Tag、Card 和 Sidebar 思路，再绑定项目自己的颜色与状态 token。

现有 WinForms 代码没有 `Microsoft YaHei UI` 的 Figma 字体可用，因此设计稿采用 `Noto Sans SC`。如果最终继续使用 WinForms，可保持当前微软雅黑；如果迁移 Web UI，建议统一切换到 Noto Sans SC，避免页面与设计稿出现字形和行高差异。
