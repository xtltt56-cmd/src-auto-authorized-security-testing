# 受控 Agent 使用说明（开发分支）

适用日期：2026-10-05。正式发布仍是 v0.11.2；这份说明仅用于 `agent/controlled-upgrade` 的本地开发版本。历史阶段验收见 [本轮进度报告](AGENT_UPGRADE_PROGRESS.md)，当前本地模型配置与验收见 [本地模型说明](LOCAL_MODEL.md)。

## 1. 它与标准检测的区别

标准检测按项目预定义的次序执行检查。受控 Agent 在入口观察/候选复核模式下读取真实工具观察，再由模型提出许可动作；在完整本地靶场评估模式下，程序先自动执行必需固定配方，再由模型核对结果并决定结束或做有限补充观察。程序验证范围、额度和证据后才执行任何动作。模型不是网络权限的来源，也不能传入任意 URL、命令、Cookie 或密钥。

当前只有固定本地靶场入口，真实目标草稿不会转成 Agent 的网络授权。它不会确认赏金漏洞，不会向补天提交报告，不执行爆破、写入、SQLi/XSS 利用载荷或破坏性测试。

## 2. 打开方式与前提

使用原有 `START_DASHBOARD.bat` 打开已构建的新版 Dashboard；开发者在 `dashboard` 中执行 `npm run build` 后，沿用原有启动器。左侧新增「受控 Agent」，无需另开密钥弹窗。

- 先到「本地靶场」启动对应靶场，等待真实状态为「就绪」。Docker 不可用时不能启动 Agent，不应把禁用按钮当成故障。
- Agent 主模型现为 **DeepSeek V4.1 Flash**，官方 API ID 为 `deepseek-flash`，复用系统设置中的既有加密密钥。不会在打开页面时调用模型。
- Qwen3.5-9B 仍作为可手动选择的本地模型，复用 `lanes.primary`，地址限 `http://127.0.0.1:11434`；不自动切换或重新下载模型。
- 保留 balanced：整机 CPU 上限 70%、已用内存上限 **30 GiB**（用户已确认调整）；同时检查项目磁盘、磁盘可用空间和 STOP。它限制整机已用内存，不是模型内存分配量。
- 若启动时选择不允许云端 AI，本次所有云端 Agent 选项被禁用，后端也会拒绝请求。保存密钥不会改变这个选择。

## 3. 新任务步骤

1. 勾选「启用本次受控 Agent」。这只打开本次执行开关，不会立即调用模型；重启后默认关闭。
2. 选择模式和本地靶场。
   - **完整本地靶场评估**：程序先自动运行所选靶场的固定验收配方，再让模型查看结果、做有限补充检查并给出人工复核摘要。Juice Shop 检查可达基线；DVWA 检查登录边界并运行布尔对照和惰性标记；WebGoat 检查登录边界和合成账号会话；VAmPI 读取 OpenAPI 表面；Business API 自动对 20 个固定合成对象做权限矩阵。它不是完整站点漏洞扫描。
   - **API 权限检查**：只对 Business API 的合成账号与已登记对象检查。账号固定为所有者、同级账号、匿名，模型只选择 `case-NN`。
   - **候选复核 / 入口观察**：可选当前靶场的历史候选，读取脱敏证据并进行许可的只读观察；不关联候选时先观察入口。不代表完整漏洞复现或最终裁决。
3. 默认选择 DeepSeek 主模型；使用云端时，启动器须先选择允许云端，页面还须勾选“同意本任务向所选云端模型发送脱敏观察”。也可手动选本地。选择最多 2、4、8 步。完整本地评估的固定配方会占用工具动作及请求额度；Business API 矩阵固定使用 60 次 GET，连同基线通常不超过默认 100 次请求。
4. 点「开始受控任务」。每任务默认最多 8 次工具动作、100 次 HTTP 请求、12 次模型调用、15 分钟、20,000 Token；只有一个任务可执行。高级接口也不能扩大这些上限。固定配方失败或未完成时，任务会转人工处理，不会被模型文字强行判为完成。
5. 在「任务与复核队列」点一个任务。右侧显示实际动作、请求、模型调用、Token、候选数、简短执行理由与工具观察 ID。
6. 点「查看完整报告」直接打开对应正文。报告、候选和执行记录都留在 D 盘；报告导出复用既有白名单、脱敏和大小限制。

当前只开放 DeepSeek 的固定本地 Agent 循环，GLM 和 OpenRouter 的 Agent 循环仍关闭，普通人工连接测试不变。仍须启动时允许云端、启用本次 Agent、单任务同意和有效密钥；任一条件缺失都拒绝调用，不自动回退其他模型。程序先运行必需固定配方，再调用模型解释、选择额外允许动作或完成人工复核摘要；完成状态要求引用配方通过的工具观察。

## 4. 如何理解结果

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 已排队 / 执行中 | 来自后端记录，不是前端倒计时 | 可在拥有该任务的控制台停止 |
| 已结束 · 待人工复核 | 模型提出结束且引用必要观察；不等于漏洞确认或无漏洞 | 阅读工具观察，人工复现和判定 |
| 已暂停 | 模型请求失败、资源或磁盘达到限制 | 先解决原因；不要反复点击启动 |
| 需要人工处理 | 达到额度、无足够证据、非法/重复动作或工具失败 | 阅读原因和报告，再决定新任务 |
| 上次执行中断 | 原执行进程已退出；没有自动续跑 | 核对是否有在途动作，再人工续接 |
| 已取消 / 执行失败 | 任务并未成功完成 | 不使用残缺报告作为验收通过证明 |

模型简述不是事实裁决。即使它写“无异常”，如果工具观察产生候选，候选仍须人工复核。响应头缺失只作为加固建议，不自动当成赏金漏洞。

Token 有真实服务商计数时使用该计数；缺失或请求超时时保守估算并标记。DeepSeek 按 2026-10-05 核验的人民币峰值价（输入 2 元、输出 8 元/百万 Token）保守估价，不按缓存或低峰折扣减少预算。每次调用前在既有 `spend` 账本原子预留 **0.064 元**，沿用每日 10 元、每月 100 元项目预算；预留并非真实费用，超时、取消及进程重启不退回预留，不自动重试。实际服务商账单可能不同，价格变化后应重新核验计价配置。账本不会包含密钥或原始提示词。

## 5. 停止、续接和恢复

- 点「停止任务」或关闭本次 Agent 开关，会设置取消标记。在途模型请求不能保证立刻中断，但有超时上限；返回后不执行下一动作。本地模型单次超时最多 120 秒，云端最多 90 秒，并受任务剩余时长缩短。
- 项目根目录 `STOP` 也会阻止下一轮及下一次目标请求。文件不存在才可开始后续任务；不要未检查原因就清除它。
- 只有「已暂停」「上次执行中断」允许人工续接。范围、模型配置、动作目录、权限规格和关联候选摘要必须不变，继续使用原额度；不能靠续接重置计数。
- 释放资源且配置不变时可以续接。更换模型或配置后应创建新任务。曾中断在途工具动作的记录不会静默重放，而是要求人工检查。
- 第二个控制台可以读取历史，不会把原服务的活动任务篡改成“中断”，也不能并行启动第二个 Agent。关闭另一实例不会停止原实例的任务。

## 6. 文件位置

所有项目产物位于 `D:\网络安全文件夹\SRC-Auto`：

- `data/agent.sqlite3`：Agent 任务、计数、观察与检查点，与既有数据库分开。
- `data/src_auto.sqlite3`：符合固定规则的未确认候选及其标准运行/报告关联。
- `reports/agent/<任务ID>.md`：脱敏执行草稿。
- `validation/agent-upgrade/`：仅本机验收截图和实验记录，不进入 Git 或正式分发包。
- `config/agent/permissions.json`：合成账号与私有/公开对象规格，不含故意脆弱/已修复的答案标签。

不要将数据库、运行报告、会话、密钥或 DPAPI 密文直接拖到公开仓库。
