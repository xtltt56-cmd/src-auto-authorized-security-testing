## 本轮发现并修复的问题

1. 测试会话缺少目标/入口/角色/过期绑定：扩展现有 DPAPI 格式，将绑定上下文与凭据共同加密，并拒绝元数据篡改、降级重绑定和非法 HTTP 头。
2. 模型提前结束可能造成覆盖假完成：必须引用全部批准对象和必要固定对照的有效观察，证据不足转人工。
3. 多条业务观察使模型上下文超限：用字段白名单压缩反馈，不向模型发送正文或内容摘要，完整证据留在本地。
4. 排队失败与报告失败可能残留关联任务 running：两份任务状态同步收敛，报告失败明确 failed；故障测试先复现再修复。
5. 会话/草稿/实例变化、取消和重定向可能跨越授权：逐请求及接收阶段校验，拒绝所有重定向，停止后不继续发送。
6. 旧服务可能无法承接新前端：启动器验证 API 版本 3 和准备/执行能力；不盲目结束其他进程。
7. 对象 ID 难以编辑、同名草稿与窄屏证据可读性不足：显式 ID 输入、实例信息、中文结果与窄屏卡片；实际浏览器复核。
8. 旧文档仍写 L4-B/C 未实现：更新 README、使用手册及计划/进度顶部，保留历史成绩但不混用。

## 安全边界与未完成事项

- 所有新业务 HTTP 仅指向本轮独立回环合成服务。没有访问外部目标、量化生产应用或交易出口。
- 本轮云端调用使用用户允许的 DeepSeek，不将凭据、响应正文、私有源码或对象摘要发送给模型。Git 与分发排除密钥、会话、数据库、报告、测试工件及合成实例登记文件。
- 对 351 个 Git 已跟踪或未忽略的源文件候选做凭据签名 / 严格 UTF-8 检查，未发现凭据签名、非法 UTF-8 或替换字符；密钥、会话、实例登记与测试工件的忽略规则另行核对。该检查不等同于未知格式秘密的绝对保证，正式发布仍要执行已有分发门禁。
- 仍由人工保证自有应用隔离，平台不自动克隆生产或运行重置命令；GET 也可能有副作用，必须人工确认精确路由。
- JSON 对比采用严格同一 ID / 全文摘要证据。动态字段、其他 JSON 结构、登录页或截断需要人工，不宣称通用 IDOR 自动确认。
- 固定 SQL/HTML 验证仅用于登记且实例一致的程序自有合成服务，未实现任意目标输入注入、盲注、存储型 XSS、脚本执行或写入/竞争条件业务测试。
- 本轮没有再次跑五个固定 Docker 靶场全流程，既有浏览器回归不等于五靶场扫描成绩。
- L4 功能增量尚未提交、推送或发布新版本。计划中的正式版本号、源码提交、CI、新 ZIP 干净安装、发行及下载同步仍需取得本次发布授权后完成；正式下载仍以 v0.13.0 为基线。
