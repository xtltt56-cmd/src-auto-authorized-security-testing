# v0.14.0 发布前准备说明

日期：2026-10-09。本文件记录发布前快照：代码已本机验收，当时正式发布等待用户当次确认和 GitHub CI。后续实际发行状态请查看 [GitHub Releases](https://github.com/xtltt56-cmd/src-auto-authorized-security-testing/releases/latest)，本文不是实时发布状态页面。

## 本次纳入的更新

- 源码审查使用实际批准文件快照、明确的排除清单与未处理文件原因；业务 data/runtime 模块不再只按名称排除，压缩第三方脚本明确排除。
- 页面展示真实阶段、耗时、文件覆盖、候选和关联报告。可选 DeepSeek 规则摘要辅助默认关闭，最多 4 次，只发送匿名规则和数量，不发送代码或文件定位。
- 云端失败保留静态结果，未处理或未审阅部分标记人工处理；STOP、资源、额度、配置和审批校验继续生效。
- 正常浏览器断连不再引发重复错误响应；未知异常和真实后端故障不被隐藏。
- 发行脚本默认重新构建 Dashboard，即使旧 dist 已存在；构建失败不得生成 ZIP。VERSION、pyproject 和 Python 包版本统一为 0.14.0。
- 业务验收判断完整、已验证的工具观察；完整覆盖后主动转人工复核属于有效结束，资源阻断、缺少控制项或未验证证据不算成功。

## 包与发布门禁

必须先保存为干净本地提交，才能打包；包内 manifest 提交号应与所准备的源码一致。每次生成包后检查固定名 ZIP、版本名 ZIP、SHA256SUMS、UTF-8 和凭据签名、私密运行目录排除、最新前端及源码字节一致性，并从新目录独立解压启动包内 Python 和真实页面。

本轮工件保存在本机 validation/release-ready-20261009，新包输出到 artifacts/release-v0.14.0-20261009-ready；它们不会提交到源码仓库。正式发布只有用户确认后才推送，GitHub Actions 必须通过后才能更新 v0.14.0 标签、Release 和固定下载地址。推送 main 会触发现有自动发行流程，不能在等待确认期间提前推送。

公开包不含 API 密钥、DPAPI 密文、测试账号会话、数据库、生成目标、私有源码、日志、报告、Ollama 权重和扫描器下载。分发用户须配置自己的密钥，并自行准备 Docker 和所需固定工具；缺依赖应明确阻止，不能显示假成功。

有限规则、合成正负例和真实调用不代表任意业务覆盖、无漏洞证明或赏金收益；所有候选均需人工复核，补天提交始终由人工完成。
