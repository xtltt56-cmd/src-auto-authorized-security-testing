# SRC-Auto Implementation Plan

> **For agentic workers:** Execute this plan inline in the current session. The user has authorized autonomous implementation within `D:\网络安全文件夹`; keep the fail-closed rule for any live target.

**Goal:** Build a low-cost, CPU-friendly, human-gated SRC assistance workflow that can run a complete local-lab E2E from scope through evidence and a draft Butian report, without contacting an unconfirmed real target.

**Architecture:** A small Python 3.8 control layer owns scope, policy, SQLite state, checkpoints, resource/disk gates, and adapters. Adapters invoke external reconnaissance tools only when the scope snapshot and policy permit; when tools are absent, the run records an explicit `UNAVAILABLE` state rather than pretending success. The local lab uses a loopback HTTP service and deterministic fixtures so every control-layer behavior is testable offline.

**Tech Stack:** Python stdlib (`argparse`, `sqlite3`, `subprocess`, `http.server`, `unittest`), JSON-as-YAML-compatible configuration, optional PyYAML, Git, and externally installed official tools when available.
