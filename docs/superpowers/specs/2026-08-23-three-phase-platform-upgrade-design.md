# SRC-Auto 三期平台升级设计

## 目标

在不削弱现有失败关闭边界的前提下，把 SRC-Auto 从本地靶场控制台升级为三类能力统一、默认安全、适合非技术操作者使用的桌面平台：

1. 外部攻击面与常见技术漏洞的受控检测；
2. 测试账号、API 对象、权限矩阵和业务规则的半自动验证；
3. 自有资产的外部暴露面快照与本地防护日志分析。

真实目标只有在人工确认的 `scope_confirmed.yaml` 和 `live_plan.yaml` 同时存在时才允许生成执行计划；平台不会自动提交报告，不会执行爆破、拒绝服务、批量对象枚举或破坏性请求。

## 总体架构

```text
中文桌面控制台
  ├─ 目标与授权 ── ScopeGuard ── 外部工具计划
  ├─ 本地靶场 ──── 仅回环 Docker 靶场与固定回归
  ├─ 业务逻辑 ──── 会话保险箱 / 请求模板 / 权限矩阵 / 响应差异
  ├─ 防护监测 ──── 域名资产快照 / 变化检测 / 本地日志导入
  └─ 结果报告 ──── SQLite / JSON / Markdown / 人工复核

成熟工具适配层
  ├─ Subfinder + httpx + Katana
  ├─ Nuclei（本机可执行文件或官方 Docker 回退）
  ├─ OWASP ZAP（被动优先，主动扫描需单独批准）
  ├─ BBOT（被动 EASM 预设）
  ├─ Schemathesis（OpenAPI / GraphQL，本地或明确授权环境）
  └─ testssl.sh（TLS 检查，Docker/Git Bash 可用时启用）
```

## 一期：工具与外部攻击面

- 工具目录固定在 `vendor/`，缓存固定在 `vendor/cache/`，不做全局安装。
- 工具清单记录版本、来源、SHA-256、运行方式和当前状态。
- Nuclei 默认只允许经过审阅的低风险模板集合、低速率和显式目标；禁止 fuzz、DoS、headless/code 模板和外带数据模板。
- BBOT 仅开放被动或最小 EASM 预设，不开放主动端口扫描和攻击模块。
- 外部资产快照只保存主机、端口、URL、协议、时间和有限元数据，不保存大段响应正文。
- 每次结果与前一次快照比较，输出新增、消失和保持不变的资产。

## 二期：业务逻辑辅助验证

- 会话资料按账号和角色管理，Cookie/Authorization 值只以 Windows DPAPI 密文保存。
- HTTP 请求模板默认只允许 GET/HEAD；修改请求必须同时满足测试账号、测试数据、人工确认和范围门控。
- 权限矩阵对同一请求执行“原账号、另一测试账号、未登录”三种上下文比较。
- JSON 响应比较会去除操作者配置的易变字段，并比较状态码、结构、对象归属字段和敏感字段。
- 对象 ID 只能来自测试账号自己的响应或人工录入，禁止连续枚举和猜测相邻 ID。
- 业务规则使用显式不变量，例如允许状态迁移、字段可见性、角色访问关系和幂等要求；AI 只能解释候选差异，不能自动确认漏洞。
- Schemathesis 作为规范驱动测试适配器；RESTler 完整 fuzz 不进入真实目标默认路径。

## 三期：防护监测

- “输入域名”创建的是待验证资产，不自动访问网络。
- SRC 项目使用人工授权范围；自有资产使用本地保存的归属证明记录。任何一个缺失都保持未授权状态。
- 外部监测计划由 DNS/证书/HTTP/TLS/安全响应头/受控模板步骤组成，并沿用 ScopeGuard。
- 日志分析只读取项目内导入副本，支持 Nginx/通用 Web、Wazuh、Zeek 和 Suricata JSON；原始日志不被修改。
- 输出事件聚合、异常状态码、可疑路径、认证失败、扫描特征和修复建议草稿。
- 封禁 IP、修改 WAF、防火墙或云配置永远只生成建议，不自动执行。

## 中文桌面界面

主窗口采用左侧导航和单一工作区，入口包括：首页、目标与授权、检测中心、业务逻辑、防护监测、本地靶场、结果报告、设置。首页仅保留三个主要动作：启动靶场、新建目标、添加自有域名。所有按钮必须有真实处理函数、忙碌状态、成功/阻止提示和可恢复错误说明。

设计参考：`docs/design/src-auto-main-console-concept-v1.png`。

## 验收

- 每个新模块先写失败测试，再实现最小功能。
- 每期运行定向测试、完整 `unittest`、PowerShell 语法解析和 UTF-8 BOM 检查。
- 本地网络验证只允许 `127.0.0.1`/`localhost` 三靶场及测试夹具。
- 图形界面使用自动点击探针验证所有一级入口，并保存实际截图与视觉核对记录。
- 最终报告明确区分：已验证、仅安装、环境阻止、需要真实授权数据才能验收。
