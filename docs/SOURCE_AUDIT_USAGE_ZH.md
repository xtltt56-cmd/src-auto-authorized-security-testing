# 源码安全审查使用说明

适用：当前本地源码审查修复版（2026-10-09）。旧验收文档中的“零模型调用”描述的是当时的测试轮次，不代表当前不支持云端摘要辅助。

## 如何操作

1. 从桌面启动器进入平台，点击左侧“源码安全审查”。仅当需要云端辅助时，在本次启动询问中允许云端 AI，并在系统设置中保存、验证 DeepSeek 配置。保存密钥不等于同意调用。
2. 粘贴项目源码目录的绝对路径，例如 `D:\我的项目\src`，选择 Python、JavaScript / TypeScript。这里不是网站地址，也不是启动命令。
3. 勾选独立的目录读取许可和临时快照许可，点击“核对源码快照”。核对不会运行扫描器或调用模型。
4. 展开批准文件清单、排除项和范围摘要。需要审查脚本时，再单独选择项目的 `scripts` 目录。更改目录、语言或授权后必须重新核对。
5. 可选勾选“DeepSeek 摘要辅助研判”（默认不勾选），然后确认按批准快照启动，点击“开始源码审查”。没有启动时的云端同意或配置未就绪时，此选项不可启用。
6. 在任务记录中选择本轮任务，查看实际阶段、文件覆盖、候选数量、耗时、模型调用和目标请求计数。停止按钮请求取消；在途云端请求可能需等超时或响应结束，之后不继续下一步。
7. 点击“查看完整源码报告”读取报告全文，再从查看器导出。按文件和行号人工确认候选；系统不会自动确认漏洞或提交补天。

## 实际能力与边界

- 复用固定版本 Bandit 1.9.4 与 Semgrep 1.179.0 和项目的受控规则集，不是完整 SAST 产品或依赖漏洞数据库。
- 扫描器在断网、受限 Docker 容器中分析批准快照。不执行目标代码、构建、依赖安装或 Git 钩子，不启动交易应用。任务结束清理自有容器和临时快照。
- 支持 UTF-8 / UTF-8 BOM；最多 2000 个文件、单文件 1 MiB、合计 20 MiB，任务期限 300 秒。超限或未知资源状态会阻止执行，不伪装成检查完成。
- 业务源码里的 `data` / `runtime` 模块不会仅按目录名被跳过；根目录的非包数据/运行产物仍排除。敏感文件名、隐藏目录、依赖、二进制、生成产物和 `*.min.js` 等会被排除，核对页面列出原因。
- 若扫描器未处理批准文件，任务标记需要人工处理，报告保留未处理清单。覆盖率只针对批准文件，不等于检查完整仓库的所有文件。
- 云端摘要辅助最多 4 次，受会话同意、任务同意、配置、共享预算、STOP、资源和时间限制共同约束。只发送匿名规则、候选数量及未验证标记；不发送源码、目录、文件名、行号、业务数据或密钥。
- 模型给的是规则组的复核建议，没有看到代码或数据流，不能据此证明漏洞、排除误报或自动重分类。云端失败保留静态结果与费用预留，展示未审阅数量，不静默重试或改用其他模型。
- 报告保存在项目的 `reports/source`，包含本地文件定位信息，但不保存原始代码。公开分享之前仍需人工检查报告中的路径和项目信息。

## 排查提示

- 页面显示服务未连接：关闭旧平台窗口后从桌面启动器重新打开，确保后端和前端加载同一修复版。页面刷新不一定更新已运行的 Python 服务。
- Docker 未就绪、STOP 存在、配置变化、资源不足或审批过期：先处理页面提示再重新核对。不要删除安全门禁绕过阻止。
- 已提交后状态暂时断连：先恢复连接并查任务记录，不要重复启动。
- 零候选仅表示本轮受控规则没有命中，不代表项目没有业务逻辑、安全配置或运行时漏洞。
