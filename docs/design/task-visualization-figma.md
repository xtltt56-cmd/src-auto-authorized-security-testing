# SRC-Auto 实时任务可视化 Figma 交付规格

状态：Figma 文件尚未创建，本文件是可直接照此建立页面的冻结规格。
目标：为 **SRC-Auto 授权安全测试编排与候选漏洞研判平台** 建立简体中文桌面界面，先完成视觉审核，再进入 React 实现。

## 设计边界

- 所有页面面向本地桌面控制台，默认状态是“本地靶场 / 未接触真实目标”。
- 真实授权目标必须先录入、复核并人工确认；保存草稿不触发网络访问。
- 页面可以展示自动化过程，但不能提供绕过范围、强制继续或自动补天提交按钮。
- 所有示例数据必须是合成数据或本地靶场数据，不得放入真实密钥、Cookie、目标账号和未公开漏洞证据。
- 视觉语言为简体中文优先，英文只在技术名词、HTTP 方法、工具名称和错误码中保留。

## 画布与断点

建立以下 Figma 页面：


DPI 评审：100%、125%、150%、200% 四组截图；缩放只改变物理像素，不改变信息层级和交互顺序。

## 共用应用框架

每个桌面页面共享以下结构：

```text
┌────────────────────────────────────────────────────────────────┐
│ 品牌 / 面包屑                         本地安全状态 / 帮助 / 设置 │
├──────────────┬─────────────────────────────────────────────────┤
│ 主导航       │ 页面标题 + 页面说明 + 当前任务/范围状态           │
│              ├─────────────────────────────────────────────────┤
│ 快速开始     │ 页面主体                                           │
│ 本地靶场     │                                                 │
│ 任务总览     │                                                 │
│ 授权目标     │                                                 │
│ 结果与报告   │                                                 │
│ 历史与恢复   │                                                 │
│ AI 设置      │                                                 │
│              ├─────────────────────────────────────────────────┤
│ 安全状态     │ 固定安全提示：本地/授权范围、无自动提交、停止键 │
└──────────────┴─────────────────────────────────────────────────┘
```

导航状态必须同时区分：

- 当前页面。
- 当前任务状态。
- 当前目标模式：`本地靶场`、`离线审阅`、`授权目标草稿`、`授权执行`。
- 远程 AI：`未启用`、`本次已启用`，不显示密钥值。

## 页面 1：任务总览

Frame：`Overview / Desktop / 1440x900`。

### 信息结构

1. 顶部状态卡：安全模式、Docker、后端、WebView2、存储路径。
2. 快速操作：`启动本地五靶场`、`录入授权目标`、`查看报告`。
3. 运行中任务表：任务名、模式、当前阶段、进度、运行时间、发现数、控制按钮。
4. 最近任务：完成、阻断、失败、等待人工确认的任务。
5. 安全提示：突出“保存目标不会访问网络”“补天提交始终人工完成”。

### 状态变体

- 空状态：`还没有任务，建议先启动本地靶场`。
- 本地任务运行：显示绿色回环标识和阶段进度。
- 等待确认：紫色门禁标识，按钮为`查看授权摘要`。
- 阻断：显示阻断原因和安全下一步，不出现绕过按钮。
- 后端断开：显示`重新连接`和`在浏览器中打开`。

## 页面 2：本地靶场启动与矩阵

Frame：`Local Labs / Matrix / 1440x900`。

### 靶场卡片

每张卡片包括：靶场名称、固定镜像摘要后缀、回环地址、健康状态、最近运行时间、候选发现数、报告入口。

应用靶场使用明确的事实标签：

- Juice Shop：`127.0.0.1:3000`。
- DVWA：`127.0.0.1:8081`。
- WebGoat：`127.0.0.1:8082`。
- VAmPI：`127.0.0.1:8083`。
- 第五个业务 API 靶场：在配置和健康检查真正加入后才显示；未实现时显示`待加入，不计入成绩`，不得伪造健康状态。

数据库容器显示为`DVWA 基础设施`，不计为独立应用靶场。

### 控件

- `启动选中靶场`。
- `仅检查健康状态`。
- `查看任务详情`。
- `停止本地靶场`。

启动按钮在 Docker 未运行时显示中文原因和`启动 Docker Desktop`提示；不自动下载未在固定清单中的镜像。

## 页面 3：任务实时详情

Frame：`Task Detail / Running / 1440x900`。

### 布局

- 左侧阶段轨道：准备、范围检查、表面发现、工具检测、归并、证据整理、人工复核。
- 中央事件时间线：按序号、时间、阶段、状态、简体中文消息显示。
- 右侧计数卡：已计划、已执行、已阻断、候选发现、错误、请求预算。
- 底部实时日志：支持过滤`全部 / 事件 / 工具 / 阻断 / 错误`。
- 顶部操作：`暂停`、`继续`、`取消任务`、`导出事件`。

### 事件视觉规则

| 事件 | 视觉 | 说明 |
|---|---|---|
| 已计划 | 灰蓝 | 仅表示计划，不代表已访问 |
| 已允许 | 蓝色 | 范围门禁通过 |
| 执行完成 | 绿色 | 完成一个受控步骤 |
| 阻断 | 紫色 | 明确显示策略原因 |
| 失败 | 红色 | 显示可恢复或需人工处理 |
| 等待人工 | 橙色 | 必须人工确认才能继续 |

页面必须能展示“暂停后没有新的请求”这一状态，不要用只会旋转的无限加载图替代真实进度。

## 页面 4：授权目标录入

Frame：`Authorization / Draft Form / 1440x900`。

采用分段表单，右侧固定显示安全摘要预览：

1. 项目基本信息：补天项目名、规则来源、规则记录时间。
2. 目标入口：起始 URL、准确主机、允许端口。
3. 排除项：排除路径、敏感操作、禁止方法。
4. 时间和预算：起止时间、最大请求数、并发、每秒速率。
5. 自动化许可：原文摘录、复选框、人工确认说明。
6. 保存草稿：按钮文案必须是`保存授权草稿（不会访问网络）`。

右侧摘要显示：

```text
当前状态：草稿，尚未授权执行
网络副作用：0
允许方法：GET / HEAD
请求预算：100
确认摘要：等待人工确认
```

表单错误必须定位到字段，例如：`端口必须为 1—65535`、`时间窗结束时间必须晚于开始时间`、`起始 URL 主机不在允许主机列表中`。

## 页面 5：授权确认对话框

Frame：`Authorization / Confirmation / 720x760`。

对话框不可通过滚动隐藏关键字段。必须显示：

- 目标主机和端口。
- 排除路径。
- 允许方法。
- 测试窗口（本地时区和 UTC）。
- 请求总预算、并发和速率。
- 自动化许可来源。
- 摘要哈希的前 12 位和后 8 位。
- `修改任意字段后需要重新确认`。
- `系统不会自动提交补天`。

确认按钮文案：`我已核对范围，确认进入授权执行队列`。
取消按钮文案：`返回修改`。
不得出现`跳过范围检查`、`强制开始`或类似按钮。

## 页面 6：阻断与边界解释

Frame：`Authorization / Blocked Action / 600x420`。

显示：


```text
操作已阻断
原因：重定向目标不在已确认主机列表
原计划：GET /account/profile
新目标：example-other.com
处理：任务已安全暂停，未发送重定向请求
下一步：查看范围、修改草稿并重新确认
```

仅提供`查看事件`、`返回范围摘要`和`取消任务`，不提供绕过门禁的操作。

## 页面 7：结果与报告

Frame：`Findings / Reports / 1440x900`。

左侧候选列表：标题、级别、状态、来源工具、是否已独立验证。
中央证据摘要：请求/响应经过脱敏和大小限制。
右侧人工研判：`未验证`、`需要复现`、`误报`、`候选漏洞`、`不提交`。

报告查看器必须支持：

- 点击文件名后打开具体内容。
- Markdown、JSON、纯文本安全渲染。
- 过长内容折叠。
- 敏感字段显示`<redacted>`。
- 复制报告路径，但不允许浏览器任意读取本地文件。

固定提示：`候选结果不是补天提交；提交必须由人工完成`。

## 页面 8：历史与恢复

Frame：`History / Recovery / 1440x900`。

任务状态卡必须说明：

- 上次事件序号。
- 中断原因。
- 是否需要重新授权。
- 原范围摘要是否仍匹配。
- 可以执行的动作：`恢复观察`、`重新确认后继续`、`复制为新任务`、`结束任务`。

服务重启后，旧 SSE 连接显示`已断开，正在从事件序号 N 续传`，不得从头重复显示为新任务。

## 页面 9：AI 设置

Frame：`Settings / AI / 720x720`。

显示 provider、模型、启用开关、最近调用次数和本次会话状态；密钥只能显示：

```text
已保存：是
显示：sk-…ce10e
读取权限：当前 Windows 用户
```

启用逻辑：

- 默认关闭。
- 每次启动询问是否启用远程 AI。
- 选择否时，状态显示`本次会话禁用，绝不会调用远程 AI`。
- 选择是时，仍只用于已确认任务的研判步骤。
- 失败时回退本地模型或人工复核，不改变授权范围。

## 页面 10：桌面启动、错误和回退

Frame：`Desktop / Startup States / 600x420`。

状态：

1. `正在启动本地服务……`。
2. `正在检查本地端口……`。
3. `控制台已就绪`。
4. `WebView2 不可用，可在系统浏览器中打开`。
5. `本地服务启动失败，查看日志或重试`。
6. `已切换到旧版界面`。

每个错误状态都提供下一步和错误编号，不显示 Python 堆栈或会话令牌。

## 页面 11：组件与交互变体

建立组件集并使用 Variants：

- `Button / Primary / Default|Hover|Pressed|Disabled`。
- `Button / Danger / Default|Hover|Disabled`。
- `StatusPill / Ready|Running|Paused|Blocked|Failed|Review`。
- `ProgressBar / 0|25|50|75|100|Indeterminate`。
- `EventRow / Planned|Allowed|Completed|Blocked|Failed|Human`。
- `LabCard / Healthy|Starting|Stopped|Blocked|Failed`。
- `ScopeField / Valid|Invalid|Excluded|ReadOnly`。
- `Dialog / Confirm|Cancel|Error`。
- `EmptyState / NoTasks|NoFindings|NoReports`。

焦点状态必须有明显 2px 高对比边框；键盘 Tab 顺序与视觉顺序一致；危险操作需要二次确认。
