# 云端 AI 密钥与模型设置

当前 Dashboard 已把 DeepSeek、智谱和 OpenRouter 配置统一放进左侧 **系统设置**，不再要求打开独立 PowerShell 输入窗口。

## 使用步骤

1. 启动平台并点击左侧 **系统设置**。
2. 选择服务商：DeepSeek V4.1 Flash、智谱 GLM-5.3-Flash 或 OpenRouter 通用入口。
3. 直接粘贴 API 密钥。第一次使用只填密钥即可采用推荐模型；替换密钥时粘贴新值，留空则保留已保存密钥。
4. 核对模型 API ID。DeepSeek 推荐 `deepseek-flash`，智谱推荐 `glm-5.3-flash`，OpenRouter 默认 `openrouter/free`；模型更名时可以在这里修改精确 ID，也可点击 **恢复推荐值**。
5. 点击 **保存设置**。该操作只写入本地配置和 Windows DPAPI 密文，不会联网；成功后明文输入框立即清空。
6. 如需验证密钥，先勾选 **允许本次联网测试**，再点击 **测试连接**。该勾选只对一次测试有效，测试只发送固定的“OK”文本，可能产生少量费用。

## 安全边界

- 密钥密文固定保存在 `config\secrets\<provider>_api_key.dpapi`，该目录不提交 Git。
- DPAPI 密文只可由保存它的 Windows 用户解密；换电脑或换用户后需要重新输入。
- 后端只向代码中固定的官方 HTTPS 地址加载相应密钥，不能通过前端修改端点或把密钥发送到自定义主机。
- 设置页只返回“是否已保存”状态，不返回密钥、长度或哈希。
- 保存密钥不等于启用远程 AI。启动会话授权、脱敏预览、摘要确认和单次人工调用门仍然有效。
- 401 通常表示密钥无效；402 表示额度不足；403 表示模型权限不足；404 多为模型 ID 更名或不可用；429 表示频率或配额限制。

旧的 `stealth/ox-alpha` 已不再作为默认配置，也不把未经官方确认的替代模型称为它的“更名版本”。OpenRouter 的实际可用模型、价格和配额以账户控制台为准。
