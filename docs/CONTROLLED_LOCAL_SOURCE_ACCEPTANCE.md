## 1. 结论与交付范围

本轮批准的统一升级已接通：自定义本地目标库 → L3 受控成熟工具 → 独立源码审查 → 真实合成验收、回归及使用说明。不是只画前端；已经产生真实 HTTP 观察、Docker 静态分析结果、SQLite 任务 / 候选和关联报告。

## 2. 复用的实现与约束

- 复用现有单 Agent、ScopeGuard、SQLite 状态 / 租约、共享用量账本、STOP / 资源门槛、中文 Dashboard 和安全报告查看器，没有新建 Agent 或认证框架。
- 新目标库仅保存草稿；载入、复制、新建空白草稿均不复用执行授权或云端同意。删除仅影响草稿。
- 原生执行器检查精确回环 IP / 端口、有限 GET/HEAD、时间窗、额度、监听进程身份与跳转。标准模式零 AI，Agent 最多 6 条路由编号，不能生成任意 URL / argv / 载荷。
- L3 只登记页面中已经批准的链接；原始正文只在内存用于受限解析，不保存或发送模型。ZAP 导入正文 / Cookie 为空的脱敏 HAR，在 `network=none` 容器内启用三个缺失响应头规则。扫描器目标请求为 0，不运行 Spider / Active Scan / 请求重放。
- 源码需独立目录读取和临时快照授权。Bandit 1.9.4 的 14 个规则及 Semgrep 1.179.0 的 4 个项目本地 JS/TS 规则只读审查批准快照，不运行项目代码、构建、安装依赖或 Git 钩子，零模型 / HTTP 调用。
- 镜像 / CLI / wheels 固定校验；镜像不自动拉取，容器不映射端口、原始项目、Docker socket 或 host alias，根只读、禁提权并限制 CPU / 内存 / 进程。只清理任务唯一自有容器与快照，不删除用户应用或原有靶场。

工具版本和摘要见 `config/integrations/passive_scanners.json`、`source_scanners.json`、`source_wheels.json`、`source_rules.json`。工具二进制、镜像和运行证据不提交 Git。

## 5. 失败历史与本轮修复

本轮并非所有尝试首次通过，以下记录保留，不被最终成功覆盖：

- 旧审批时间窗因时间已过去被守卫拒绝，但 API / UI 未识别 `outside_test_window`，只有泛化错误。先补失败用例，再接通准确中文提示。
- 「新建空白草稿」只清名称，没有清旧入口 / 审批；交互用例先失败，再改成完整清除表单与执行 / 云端同意。
- 源码快照磁盘写入中途失败时，文件尚未登记所有权，可能残留；先补部分写入失败用例，修复为写入前登记并清理。超额 HAR 在创建目录前拒绝，避免空任务目录残留。
- 高频守卫调用曾反复重置 Windows 累计 CPU 计数，极短采样放大计时量化。改为至少 250 ms 的真实采样窗口、首次测量而非伪造 0%；70% / 30 GiB 上限未改变。新的计数器回归同时验证真实高负载仍拒绝。
- 后续真实对照仍出现 CPU 79.86%、87.63%、89.49% 等越限中断，属于未完整完成，不能算成功。记录见 `20261006-203029-604044`、`20261006-203342-478488`、`20261006-204051-104133`。任务保留已有观察和部分报告，不自动重启；需要降低工作负载、重新审批。
- Agent 自有资源检查没有更新最终读数、工具内资源拒绝被写成 `tool_failed`。分别补失败回归后修复：保存真正的最后采样，已知常量原因写进轨迹，任意异常正文仍不落盘。
- 云端验收脚本在被动结果为空时二次报错，遮住原始资源拒绝；改为空结果按失败检查记录。原失败目录 `20261006-202743-612563` 仍保留。
- 增加被动阶段后模型提示变大，原有 6 路由回归超过 6000 字节。只压缩发给模型的元数据投影，完整本地记录不变；没有放宽上下文上限，针对性回归通过。
- 工具准备脚本原来在缓存有效时仍强制拉取，Docker 的失效系统代理导致联网失败。先补缓存复用失败用例，再只对缺失固定镜像拉取，已验证本机离线缓存准备成功；未改系统代理。
- 修复源码两项授权文案过密、本机配方下拉框窄屏溢出 8 像素。最终生产截图、实际测宽和中文替换字符检查均通过。

这些资源限额意味着高负载电脑不保证每一轮完成；本轮没有为了通过关闭资源守卫、防火墙、证书校验或放宽范围。没有对环境限制宣称永久根治。

## 6. 剩余边界与发布状态

1. 真实量化应用的独立路由 / 业务副作用审查与报告未在本轮执行；只能把合成测试用于流程验收。
2. L4 隔离账号 / 数据、真实业务逻辑正反对照及 IDOR / XSS / SQLi 本机受控用例尚未接通；不能把现有五靶场的历史记录套用到新应用。

5. 当前 CLI / 镜像版本已固定，兼容其他 Docker Desktop 版本需另行核验。下载失败不会放弃完整性检查。
