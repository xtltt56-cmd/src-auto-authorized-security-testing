# 可视化升级验收记录（2026-08-26）

## 验收范围

本记录针对代码优先的 React + Vite 中文控制台纵向切片，覆盖概览、任务详情、靶场矩阵、授权目标草稿、候选与报告查看器。页面默认只读取固定本地夹具；本轮不会访问真实目标，也不会连接远程 AI 或外部网络。

视觉参考采用 `design/frontend-mockups/2026-08-25/01-安全测试工作台.png` 至 `07-代理与API复核.png`。参考稿用于信息层级、色彩和安全提示的方向校准，交互和文字以当前可运行实现为准。

## 逐项对比

| 检查项 | 参考方向 | 当前实现 | 结论 |
| --- | --- | --- | --- |

## 有意保留的差异与边界

1. 视觉稿中的后端实时 SSE、FastAPI、WebView2 和真实 Burp/ZAP 代理尚未接入；当前 repository 是可替换接口，便于下一阶段在不改页面交互的前提下接入回环服务。
2. 目标录入只保存授权草稿并计算范围摘要，不会根据输入自动请求目标；真实目标仍需人工确认授权后由后端安全门禁放行。
3. 夹具中的 Finding 和报告是脱敏演示数据，不能作为真实漏洞结论或补天提交材料。
